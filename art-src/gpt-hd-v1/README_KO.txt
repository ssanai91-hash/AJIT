아지트 고화질 배경·팔 분리 시안 v1 — 2026-11-01

첨부한 현재 화면과 이전 고화질 인물 일러스트를 참고해 기본 이미지 생성 도구로 만든 원본 시안이다.
24×32 축소나 고정 키 색 변환을 적용하지 않았다. 이전 캐릭터 시험 ZIP을 교체하지 않는 별도 고화질 시안이다.

포함 파일
preview/bar_scene_preview.png : 고화질 술집을 적용하고 가운데 인물이 잔을 든 화면 콘셉트. 실제 게임 실행 화면이나 애니메이션 녹화가 아니다.
background/bg_bar_back.png : 인물과 앞쪽 카운터가 없는 후면 술집 배경, 1536×1024.
foreground/furn_counter_front.png : 별도 RGBA 전경 카운터, 1536×1024.
characters/char_01_parts.png : 남색 니트·얇은 안경·마른 남성. 현재 화면 왼쪽 인물.
characters/char_02_parts.png : 회청색 니트·검정 안경·둥근 남성. 현재 화면 가운데 인물.
characters/char_03_parts.png : 갈색 카디건·웨이브 머리·안경 없는 남성. 현재 화면 오른쪽 인물.
atlas_regions.json : 세 인물 원본에서 부품을 읽을 수 있는 사각 영역 안내. 어깨 회전점은 아직 지정하지 않았다.
file_checks.json : PNG별 실제 크기·모드·알파 범위·SHA-256.

인물 원본은 각각 1254×1254 RGBA PNG이다. 하나의 파일 안에 네 부품이 떨어져 그려져 있다.
왼쪽 위: 고정할 머리·몸통 + 왼팔. 움직일 오른팔(화면 왼쪽)은 제거된 베이스.
오른쪽 위: 분리된 오른팔의 내려놓은 자세.
왼쪽 아래: 오른팔로 잔을 들어 건배하는 자세.
오른쪽 아래: 오른팔로 잔을 입 쪽에 가져가는 자세.

주의: 균등한 2×2 격자로 자르면 안 된다. 생성 원본이 정확한 격자 배치를 지키지 않아, 부품 사이 여백을 기준으로 별도 영역을 적었다.
atlas_regions.json은 육안으로 확인한 초기 분리 영역이며, 실제 등록·합성 시험은 아직 하지 않았다.
각 팔은 캔버스 안 위치·길이·어깨 각도가 조금씩 다르므로, 잘라낸 뒤 같은 위치에 놓는 것만으로 즉시 연결되는 완성 스프라이트가 아니다.

클로드 접합 순서
1. 후면 배경 → 인물 고정 베이스 → 전경 카운터 순으로 배치한다.
2. 선택한 오른팔 부품을 어깨 접점에 맞춰 얹는다. 휴식/건배/한 모금 중 하나만 표시한다.
3. 머리·몸통의 위치와 크기는 동작 중 바꾸지 않는다. 팔의 포즈 교체·짧은 회전으로 테스트한다.
4. 잔은 건배/한 모금 팔에 이미 포함되어 있다. 팔이 잔을 들면 테이블 위의 해당 잔을 숨겨 중복 표시를 막는다.
5. 반대팔은 현재 베이스에 포함되어 고정된다. 양팔 동작·손인사·따르기는 추가 부품이 필요하다.
6. 소매/어깨 연결부 가림, 투명 경계, 잔과 입의 위치를 실제 배치 크기에서 보정한다.

확인한 제한
- PNG에 실제 알파 채널과 완전히 투명한 픽셀이 있음을 확인했다. 화면에서 검정으로 보이는 바깥 영역은 알파가 투명한 영역일 수 있다.
- 일부 인물 가장자리에 붉거나 밝은 색 테두리가 보여 경계 정리가 남아 있다.
- 팔은 어깨부터 손까지 한 부품이다. 상완/전완/손목 각각을 움직이는 리깅 자료는 아니다.
- 몸통·팔을 합쳐 실제 어깨가 매끄럽게 이어지는지, 손과 잔이 입에 닿는지는 아직 검증하지 않았다.
- 후면 배경은 이번 화면 시험을 위해 술장·조명·주크박스를 함께 그린 합성 배경이다. 가구를 옮기는 꾸미기용 빈 bg_room이나 가구별 최종 분리 세트가 아니다.
- 배경 시안, 전경 카운터, 인물 부품은 별도 생성되어 색감·조명·축척에 조정이 필요할 수 있다.
- 프리뷰는 분위기 확인용 이미지다. 가운데 인물이 손에 든 잔과 테이블 잔이 함께 보이므로, 구현에서는 위 중복 표시 규칙을 적용한다.
- 배경은 모바일 뷰포트에 맞는 크롭/화면 이동 범위를 정해야 한다. 현재 앱 코드·서버·배포는 수정하지 않았다.

다음 합격 기준
가운데 인물 하나로 어깨 접점을 맞춘 후 몸통 고정 상태에서 대기→건배→대기로 바뀌고, 테이블 잔이 중복되지 않으며, 소매와 얼굴 경계가 자연스러운지 확인한다. 같은 방식으로 나머지 두 인물에 적용한다.
