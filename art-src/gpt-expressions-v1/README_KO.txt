클로드 적용 안내
1. 먼저 각 표정을 이름·설명·아이보리 배경과 분리해 얼굴/머리 PNG로 추출한다.
2. 시트는 생성된 비교 시안이므로 단순히 3등분한 프레임을 그대로 사용하지 않는다. 얼굴 중심·귀·턱·목 위치를 확인하며 자른다.
3. 기본 표정을 기준으로 머리 크기·귀 높이·턱·목 접점을 정렬해, 교체 시 얼굴이 튀거나 몸통이 이동하지 않게 한다.
4. 기존 몸통 베이스에 머리가 붙어 있으므로, 새 표정과 기본 얼굴이 겹치지 않도록 베이스에서 기존 머리를 분리하거나 확실한 가림 영역을 만든다.
5. 몸통·팔 상태와 표정 상태는 분리한다. 예: 웃는 표정 + 건배 팔이 동시에 가능하게 한다.
6. tipsy / drunk_sleepy는 게임 내 캐릭터 표현이다. 실제 사용자의 취기를 판정하는 정보로 사용하지 않는다.
7. 채팅에서 감정을 자동 판정하는 기능은 이번에 구현하지 않았다. 우선 표정 직접 선택으로 시험하고 자동 제안은 별도 검토한다.

현재 검증 범위
- 이미지 파일을 열 수 있는지, 실제 크기와 파일명, ZIP 무결성을 검사했다.
- 눈·코·입의 세밀한 모양과 고개 각도가 표정마다 조금 달라 완벽히 같은 좌표의 교체형 얼굴로 등록된 상태는 아니다.
- 표정 시트는 불투명한 비교용 그림이다. 투명 배경 에셋 추출·경계 보정·목 연결은 남아 있다.
- base_assets는 앞서 전달한 고화질 초안이며 해당 폴더 README의 어깨 접점·팔 정렬·경계 보정 제한이 그대로 적용된다.
- 실제 게임 조립·웹 구동·동기화·표정 교체 동작 시험은 하지 않았다.
- 얼굴 표정과 팔 동작이 결합된 완성 애니메이션 세트가 아니다.

첫 시험 권장 순서
숭열의 기본→미소→큰웃음 표정 세 장을 정렬해 같은 몸통에 교체하고, 건배 팔을 동시에 표시한다. 목/안경/머리 위치가 자연스러운지 확인한 뒤 나머지 표정과 두 인물로 확대한다.
