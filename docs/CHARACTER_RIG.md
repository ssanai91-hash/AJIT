# 고화질 캐릭터 접합·표정 수정 (2026-11-01)

캐릭터 번호: 1 찬수 / 2 정인 / 3 숭열. 서버 상태와 멤버 토큰 형식은 변경하지 않는다.

## 바뀐 방식

- 대기는 팔 소매 구멍이 없는 기존 `demo/img/bust{n}.webp` 원본을 사용한다.
- 건배·한 모금은 기존 합성 그림과 원본 bust를 참조해 이미지 생성 도구로 어깨가 이어진 전체 인물 6장을 보완했다. `art-src/rig-v2/c{n}_{toast|sip}.webp`가 프로젝트용 원본이다.
- `demo/rig.js`는 원본 bust 좌표계의 SVG를 만든다. 동작 그림은 양쪽 눈에 맞춘 유사변환으로 배치한다.
- 감정은 머리 전체를 덮지 않는다. 양쪽 눈과 입 3점의 아핀변환 + 얼굴 내부의 부드러운 두 영역 마스크로 눈·눈썹·입만 바꾼다. 머리카락, 귀, 턱 외곽, 목, 옷과 비교용 그림의 배경은 교체하지 않는다.
- 표정/자세 전환에 확대·등장 효과나 교차 페이드를 넣지 않아 두 얼굴이 겹쳐 보이지 않는다. 한 모금 중에는 표정 덮개를 숨겨 잔·손을 보존한다.

## 다시 만들기

등록 좌표: `art-src/rig-v2/registration.json`. 좌표는 각 원본의 눈 중심 두 곳과 입 중심이다. 표정 좌표는 원본 비교 시트의 좌표에서 cell origin을 뺀 값이다.

```
python3 tools/hd/build_rig.py  # Pillow 필요. 그림을 새로 그리거나 자르지 않고 WebP와 좌표 데이터만 패키징
python3 tools/build_web.py    # 준비된 그림·rig.js·rig-data.js를 worker/public으로 복사
```

`/rig-check.html`: 3명 × 9표정의 대기/건배/한 모금을 비교한다.
`/rig-play.html`: 동일한 바 화면을 로컬 가상 친구로 확인한다. 실제 좌석·채팅에 영향이 없고 브라우저 저장 키도 분리돼 있다. 두 경로는 개발 확인용이며 일반 입장 화면에서 연결하지 않는다.

## 동작 그림 편집 프롬프트 요약

도구: 기본 내장 imagegen, 투명 배경.
각 캐릭터/자세마다: “기존 동작 합성본을 편집 대상으로, 동일 인물의 온전한 bust를 신원·의상 참조로 사용. 얼굴·머리 각도·몸통·다른 손을 유지. 뷰어 왼쪽 어깨와 상완을 끊김 없이 연결하고 소매 구멍·타원 접합선 제거. 팔꿈치를 몸 가까이 굽힘. 건배는 자기 관자놀이 옆 높이에 잔, 한 모금은 자기 입술에 잔. 같은 따뜻한 2D 일러스트, 배경·그림자·가구 없이 투명 PNG.”

생성 PNG는 별도로 보존하고, 프로젝트에는 크기 변경 없이 WebP로 인코딩한 파일을 넣었다. 실제 게임 좌표 맞춤은 SVG 렌더러가 수행한다.
