## 3. 그림 조립 방식 (종이인형)

```
배경(bg_bar.webp) → 인물(자세 합성 이미지) → [표정 얼굴 덮개] → 앞 카운터(counter.webp) → 잔·병 → 말풍선
```

- **자세**: 몸통 베이스 + 팔 1개(휴식/건배/한 모금)를 미리 합성한 이미지 3장(`c{n}_rest|toast|sip.webp`). 세 장은 같은 캔버스 크기라 겹쳐 두고 하나만 보이게 전환 → 머리·몸통은 절대 안 움직임.
- **표정**: 몸통과 별개로 머리만 덮는 투명 PNG(`c{n}_face_{표정}.webp`). 자세와 동시에 가능 (웃으며 건배).
- 화면 배치값(`w/h/cx/bottom`)은 `demo/ajit-bar.html`의 `const P = {...}`.

재생성 (저장소 루트에서):
```
python3 tools/hd/build_hd.py -42 -55 demo/img     # 자세 3장 × 3명 (인자: 건배·한모금 팔 회전 각도)
python3 tools/hd/reg.py                           # 표정 27장을 자세 이미지 머리 위치에 정렬 → demo/img/c{n}_face_*.webp
python3 tools/premium_shelf.py <bg 원본> <출력>   # 윗단 '귀빈석' 진열장 (코드로 그린 임시본)
```

## 4. 알려진 문제 (GPT가 손볼 곳)

1. **표정 얼굴이 안 맞음** (형 확인). 원인:
   - 표정 시트는 비교용 그림이라 머리 크기·기울기·위치가 몸통 그림의 머리와 다름.
   - 지금은 '크기 + 위치'만 맞추고 회전은 안 맞춤. 특히 정인 몸통은 고개가 기울어 있는데 표정 얼굴은 똑바름.
   - 몸통 베이스에 원래 머리가 붙어 있어서, 표정 얼굴 가장자리로 원래 머리가 비침.
   - **제대로 된 해결**: (a) 머리를 뗀 몸통 베이스 + (b) 같은 크기·각도·목 위치로 그린 표정 머리 9장. 머리 PNG의 목 접점 좌표를 함께 주면 그대로 끼움.
2. **어깨 접합부 어긋남** (형 확인). 팔을 떼어낸 자리를 니트 색으로 메웠지만(`*_base_fix.png`), 팔 부품의 소매 끝 모양·각도가 몸통 어깨선과 맞지 않음.
   - **해결**: 팔 부품마다 '어깨 회전점' 좌표를 지정하고, 소매 끝이 어깨 안쪽으로 겹쳐 들어가도록 여유분(20~30px)을 그려 주면 됨.
3. 손 흔드는 팔·병 든 팔 없음 (손인사는 지금 몸만 들썩임).
4. 윗단 고급 진열장은 클로드가 코드로 그린 임시본 → 같은 그림체로 다시 그리면 좋음. **실제 브랜드 병·라벨 금지.**
5. 방 꾸미기용 '빈 방 + 가구 따로' 아직 없음.
